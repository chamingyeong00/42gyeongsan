# 42GYEONGSAN

42 경산 과정에서 수행한 주요 과제들을 정리한 저장소입니다.  
C 기반의 저수준 프로그래밍부터 자료구조, 알고리즘, 프로세스/스레드, 네트워크, 그래픽스, C++까지 단계적으로 학습하며 **문제를 직접 구현하고 디버깅하는 방식으로 개발 역량을 쌓은 과정**을 담고 있습니다.

각 프로젝트는 단순히 기능을 만드는 데서 끝나지 않고,  
제한된 환경 안에서 **왜 이런 구조로 구현해야 하는지**, **어떤 문제가 발생할 수 있는지**, **어떻게 더 안정적으로 동작하게 만들 수 있는지**를 고민하며 진행했습니다.  
세부 내용은 각 디렉토리의 README에 정리했습니다.

## Projects

- **C_Piscine** : C 언어와 쉘의 기초를 실습 중심으로 익힌 입문 과정
- **Libft** : 표준 라이브러리 일부를 직접 구현하며 기본기 강화
- **ft_printf** : 가변 인자와 형식 지정자 파싱을 활용한 출력 함수 재구현
- **get_next_line** : 파일 디스크립터에서 한 줄씩 안정적으로 읽는 로직 구현
- **Born2beroot** : 가상 머신과 리눅스 서버 환경 설정 및 시스템 기초 학습
- **push_swap** : 제한된 연산으로 정렬을 수행하는 알고리즘 과제
- **Philosophers** : `pthread`와 mutex를 이용한 동시성 제어 및 멀티스레드 구현
- **NetPractice** : 네트워크 주소 체계와 라우팅 기초 학습
- **Pipex** : 프로세스, 파이프, 리다이렉션을 활용한 셸 동작 이해
- **CPP** : 객체지향 개념을 기반으로 한 C++ 모듈 학습
