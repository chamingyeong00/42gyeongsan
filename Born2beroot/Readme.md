# Born2beroot

42 커리큘럼의 **Born2beroot** 과제를 수행하며, 리눅스 서버 환경의 기초 설정과 시스템 관리 방법을 학습한 프로젝트입니다.  
이 과제는 단순히 운영체제를 설치하는 것을 넘어, **가상 머신 구축, 사용자 및 권한 관리, 보안 설정, 서비스 운영, 시스템 모니터링**을 직접 구성하고 이해하는 데 목적이 있습니다.

---

## 프로젝트 소개

Born2beroot는 가상 머신 위에 리눅스 서버를 설치하고,  
안전하게 운영할 수 있도록 기본적인 보안 정책과 시스템 설정을 직접 적용하는 실습 과제입니다.

이 프로젝트에서는 운영체제를 설치한 뒤 다음과 같은 요소를 구성해야 합니다.

- 가상 머신 환경 구축
- 파티션 및 LVM 설정
- 사용자 및 그룹 관리
- SSH 서비스 설정
- 비밀번호 정책 강화
- sudo 권한 관리
- 방화벽 설정
- 시스템 상태 모니터링 스크립트 작성

**하나의 서버를 직접 설치하고, 보안적으로 더 안전한 상태로 운영할 수 있도록 설정하는 과정**을 통해 시스템 관리의 기본기를 익히는 프로젝트입니다.

---

## 구현 목표

이 프로젝트에서 집중한 부분은 다음과 같습니다.

- 가상 머신 기반 리눅스 서버 환경 구축
- 파티션 구조와 LVM 개념 이해
- 사용자 계정 및 권한 관리 방법 학습
- SSH를 통한 원격 접속 환경 설정
- 비밀번호 정책 및 sudo 정책 강화
- 방화벽을 통한 네트워크 접근 제어
- 시스템 상태를 자동으로 확인하는 모니터링 스크립트 구현

## 주요 구현 내용

### 1. 가상 머신 및 운영체제 설치
Born2beroot는 실제 물리 서버가 아니라 **가상 머신 환경** 위에서 리눅스 시스템을 구축하는 프로젝트입니다.

- Virtual Machine 환경 생성
- 리눅스 배포판 설치
- GUI 없이 서버 환경 중심으로 구성
- 기본적인 네트워크 및 호스트 설정 적용

이를 통해 운영체제가 실제로 어떤 환경 위에 설치되고 동작하는지 이해할 수 있었고,  
서버는 일반 데스크톱 환경과 달리 더 단순하고 안정적으로 구성된다는 점도 함께 학습할 수 있었습니다.

---

### 2. 파티션 및 LVM 구성
디스크를 단순히 하나의 영역으로 사용하는 대신,  
여러 파티션으로 나누고 LVM(Logical Volume Manager)을 활용해 저장 공간을 구성했습니다.

- 루트(`/`)와 기타 디렉토리의 역할 이해
- 디스크 파티션 분리의 목적 학습
- LVM을 통한 유연한 저장 공간 관리 방식 이해

이를 통해 서버 환경에서는 단순한 저장보다  
**관리 편의성, 보안, 안정성**을 고려한 디스크 구성이 중요하다는 점을 이해할 수 있었습니다.

---

### 3. 사용자 및 권한 관리
시스템을 안전하게 운영하기 위해 사용자 계정과 그룹 권한을 명확히 설정했습니다.

- 일반 사용자 계정 생성
- 특정 그룹에 사용자 추가
- `sudo`를 통한 관리자 권한 제어
- root 직접 사용보다 제한된 권한 상승 방식 이해

이를 통해 여러 사용자가 함께 사용하는 시스템에서는  
누가 어떤 권한을 가지는지 구분하는 것이 매우 중요하다는 점을 학습할 수 있었습니다.

---

### 4. SSH 및 원격 접속 설정
서버는 보통 원격으로 관리되기 때문에 SSH 설정이 중요합니다.

- SSH 서비스 활성화
- 지정된 포트를 통한 접속 설정
- root 직접 로그인 제한
- 원격 접속이 가능한 서버 환경 구성

이를 통해 단순히 로컬에서만 사용하는 시스템이 아니라,  
외부에서 접속 가능한 서버를 보다 안전하게 운영하는 기본 원칙을 익힐 수 있었습니다.

---

### 5. 비밀번호 정책 및 sudo 보안 강화
서버 보안의 기본은 계정과 인증 정책입니다.  
Born2beroot에서는 비밀번호 규칙과 sudo 사용 정책을 강화하는 작업을 수행했습니다.

- 비밀번호 길이 및 복잡도 규칙 설정
- 비밀번호 만료 주기 설정
- 재사용 제한 및 변경 규칙 적용
- sudo 사용 기록 및 제한 설정

이를 통해 계정 보안은 단순히 비밀번호 하나를 정하는 문제가 아니라,  
시스템 전체의 보안 수준을 결정하는 중요한 요소라는 점을 이해할 수 있었습니다.

---

### 6. 방화벽 설정
서버에 불필요한 접근을 막기 위해 방화벽을 설정했습니다.

- 방화벽 활성화
- 필요한 포트만 허용
- SSH 접속 포트 관리
- 외부 접근 통제 방식 이해

이를 통해 서버 보안은 단순히 내부 설정만으로 끝나는 것이 아니라,  
네트워크 레벨에서 어떤 접근을 허용할지 결정하는 것도 매우 중요하다는 점을 학습할 수 있었습니다.

---

### 7. 시스템 모니터링 스크립트 작성
시스템 상태를 주기적으로 확인하기 위해 모니터링 스크립트를 작성했습니다.

- 운영체제 아키텍처
- CPU 및 메모리 사용량
- 디스크 사용량
- 부팅 시간
- 활성 세션 수
- 네트워크 정보
- sudo 사용 횟수

이를 통해 단순히 서버를 설치하는 것에서 끝나지 않고,  
현재 시스템 상태를 주기적으로 점검하고 관리자에게 보여주는 자동화 방식까지 경험할 수 있었습니다.

## 문제 해결 방식

Born2beroot 과제를 수행할 때는 보통 아래 순서로 접근했습니다.

1. 가상 머신 생성 및 운영체제 설치
2. 디스크 파티션 및 LVM 구성
3. 사용자와 그룹 설정
4. sudo 정책과 비밀번호 정책 적용
5. SSH 및 방화벽 설정
6. 시스템 모니터링 스크립트 작성
7. 전체 설정 검토 및 테스트

이 과정을 통해 서버를 단순 설치하는 수준이 아니라,  
**실제로 운영 가능한 형태로 구성하고 점검하는 흐름**을 익힐 수 있었습니다.
