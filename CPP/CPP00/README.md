# CPP Module 00

> 42 Cursus CPP Module 00 과제 README

## 개요

CPP Module 00은 42 Cursus에서 C 언어 이후 처음 접하는 C++ 과제로,
C++의 기본 문법과 객체지향 프로그래밍 개념에 익숙해지는 것을 목표로 합니다.

## 학습 내용

* C++ 기본 문법
* 클래스(Class)와 객체(Object)
* 접근 지정자 (`public`, `private`)
* 멤버 함수
* 표준 입출력 스트림 (`std::cout`, `std::cin`)

## 과제 구성

* 여러 개의 exercise(ex00, ex01, ...)로 구성됨
* 각 exercise는 독립적으로 컴파일 및 실행 가능

## 컴파일 방법

```bash
c++ -Wall -Wextra -Werror *.cpp -o program
```

## 실행 방법

```bash
./program
```

## 주의사항

* C++98 표준을 기준으로 작성
* 메모리 누수 없이 구현해야 함
* 과제 요구사항 및 코딩 규칙을 준수함
