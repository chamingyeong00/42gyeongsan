# CPP Module 01

## 개요

**메모리 관리, 참조(reference), 포인터(pointer), 클래스 기본 구조**를 중심으로 학습합니다. C 스타일 프로그래밍에서 벗어나 C++다운 사고방식을 익히는 것이 핵심이에요.

이 모듈에서는 스택과 힙의 차이, 객체 수명(lifetime), 참조 전달 방식, 간단한 클래스 설계 등을 실습을 통해 이해하도록 구성되어 있습니다.

---

## 학습 목표

* C++에서의 메모리 관리 개념 이해
* 포인터와 참조의 차이와 사용 목적 구분
* 클래스와 객체의 기본 구조 학습
* new / delete를 이용한 동적 할당 이해
* 함수 인자 전달 방식(value / reference / pointer) 비교

---

## 과제 구성

### ex00 – BraiiiiiiinnnzzzZ

* **Zombie 클래스**를 구현하는 과제입니다.
* 스택에 생성되는 Zombie와 힙에 생성되는 Zombie의 차이를 이해하는 것이 목적이에요.
* `newZombie()`와 `randomChump()` 함수를 통해 객체 생성 위치에 따른 동작 차이를 확인합니다.

**핵심 포인트**

* 스택 객체와 힙 객체의 수명 차이
* `delete`의 필요성

---

### ex01 – Moar brainz!

* 여러 개의 Zombie를 한 번에 생성하는 **zombieHorde** 함수를 구현합니다.
* 동적 배열 할당을 통해 객체 여러 개를 관리하는 연습을 합니다.

**핵심 포인트**

* `new[]` / `delete[]` 사용법
* 반복문을 통한 객체 초기화

---

### ex02 – HI THIS IS BRAIN

* 포인터와 참조의 차이를 출력 결과로 확인하는 과제입니다.
* 같은 문자열을 포인터와 참조로 접근했을 때의 주소와 값을 비교합니다.

**핵심 포인트**

* 포인터와 참조의 개념적 차이
* 메모리 주소 출력 이해

---

### ex03 – Unnecessary violence

* **Weapon, HumanA, HumanB 클래스**를 구현합니다.
* 참조와 포인터를 멤버 변수로 사용할 때의 차이를 이해하는 것이 목표입니다.

**핵심 포인트**

* 참조 멤버는 반드시 초기화가 필요함
* 포인터 멤버는 NULL 상태를 가질 수 있음
* 설계 의도에 따른 자료형 선택

---

### ex04 – Sed is for losers

* 파일을 읽고 문자열을 치환하여 새로운 파일로 저장하는 프로그램을 작성합니다.
* C++의 파일 입출력(`ifstream`, `ofstream`)을 활용합니다.

**핵심 포인트**

* 파일 스트림 사용법
* 문자열 탐색 및 치환 로직
* 예외 상황 처리(파일 열기 실패 등)

---

### ex05 – Harl 2.0

* **Harl 클래스**를 구현하고, 로그 레벨에 따라 다른 메시지를 출력합니다.
* 함수 포인터 또는 switch 구조를 활용해 구현할 수 있습니다.

**핵심 포인트**

* 멤버 함수 포인터 개념
* 문자열 비교를 통한 분기 처리

## 컴파일 방법

```bash
c++ -Wall -Wextra -Werror -std=c++98 *.cpp -o program
```

과제 요구사항에 따라 **C++98 표준**을 사용해야 합니다.

---

## 주의 사항

* 메모리 누수(leak)가 발생하지 않도록 `new`와 `delete`를 정확히 짝지어 사용해야 합니다.
* 과제별로 요구되는 출력 형식과 함수 시그니처를 반드시 지켜야 합니다.
* Norm 규칙과 컴파일 플래그를 항상 확인하세요.

## 정리

CPP01은 이후 모듈에서 반복적으로 사용되는 **메모리 관리와 참조 개념의 기초**를 다지는 중요한 단계입니다. 단순히 동작만 맞추는 것이 아니라, *왜 이렇게 설계해야 하는지*를 이해하고 넘어가는 것이 좋습니다.

차분히 하나씩 구현해 보면 C++의 구조가 자연스럽게 익혀질 거예요.
