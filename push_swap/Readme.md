# Push_swap

## 프로젝트 소개
`push_swap`은 42 커리큘럼의 정렬 알고리즘 과제로, 두 개의 스택과 제한된 명령어만 사용해 숫자들을 오름차순으로 정렬하는 프로그램입니다.  
이 프로젝트의 핵심은 단순히 정렬 결과를 만드는 것이 아니라, **허용된 연산만으로 가능한 적은 명령어를 출력하는 것**입니다.

프로그램은 입력된 정수들을 스택 A에 저장한 뒤, 보조 스택 B를 활용하여 정렬을 수행합니다.  
이 과정에서 `swap`, `push`, `rotate`, `reverse rotate` 연산만 사용할 수 있으며, 모든 정렬 과정은 명령어 형태로 출력됩니다.

또한 잘못된 입력에 대한 예외 처리, 중복 검사, 정렬 여부 사전 확인, 그리고 입력 크기에 따라 다른 전략을 적용하는 방식까지 함께 구현하는 것이 중요한 프로젝트입니다.

---

## 구현 목표
이 프로젝트에서 중점적으로 구현한 목표는 다음과 같습니다.

- 제한된 스택 연산만 사용한 정렬 로직 구현
- 입력값에 대한 예외 처리 강화
- 중복 값 및 `int` 범위 초과 검사
- 연결 리스트 기반 스택 자료구조 설계
- 실제 값 대신 **상대적 순위(index)** 를 이용한 정렬 단순화
- 입력 크기에 따라 작은 정렬과 큰 정렬을 분리한 전략 설계
- 명령어 수를 줄이기 위한 효율적인 정렬 방식 적용

---

## 주요 구현 내용

### 1. 입력 검증
정렬을 시작하기 전에 입력값이 유효한지 먼저 검사하도록 구현했습니다.

대표적으로 검사한 항목은 다음과 같습니다.

- 숫자가 아닌 문자가 포함되어 있는지
- `int` 범위를 벗어나는 값이 있는지
- 중복된 숫자가 존재하는지
- 공백으로 묶인 문자열 입력도 정상적으로 처리되는지

이를 통해 잘못된 입력이 들어오면 `Error`를 출력하고 즉시 종료하도록 구성했습니다.

---

### 2. 연결 리스트 기반 스택 구현
스택 A와 스택 B는 **연결 리스트**로 구현했습니다.

각 노드는 다음 정보를 가집니다.

- 실제 숫자 값 (`val`)
- 정렬용 상대 순위 (`index`)
- 다음 노드를 가리키는 포인터 (`next`)

이를 통해 `push`, `swap`, `rotate`, `reverse rotate` 연산을  
스택의 top 기준으로 자연스럽게 처리할 수 있도록 구성했습니다.

---

### 3. index 기반 정렬
입력값 자체를 직접 비교하기보다,  
각 숫자에 대해 **정렬 순서를 기준으로 index를 부여한 뒤** 정렬하도록 구현했습니다.

이 방식을 사용하면 실제 값의 크기와 관계없이  
항상 `0 ~ n-1` 범위의 index만 다루면 되기 때문에 정렬 로직을 단순하게 만들 수 있습니다.

또한 radix sort를 적용하기 쉬운 형태로 변환할 수 있다는 장점도 있습니다.

---

### 4. 입력 크기에 따른 정렬 전략 분리
입력 개수에 따라 서로 다른 정렬 방식을 적용했습니다.

- **3개 이하**: 최소한의 `swap`, `rotate`, `reverse rotate`로 직접 정렬
- **5개 이하**: 작은 원소를 스택 B로 분리한 뒤 정렬하고 다시 복구
- **6개 이상**: index를 기반으로 한 **binary radix sort** 적용

이를 통해 작은 입력은 단순하게, 큰 입력은 효율적으로 처리하도록 구성했습니다.

---

### 5. 정렬 여부 사전 확인
이미 정렬된 입력에 대해서는 불필요한 연산을 하지 않도록,  
정렬을 시작하기 전에 먼저 현재 스택 상태를 검사하도록 구현했습니다.

이를 통해 불필요한 명령어 출력 없이 더 깔끔하게 프로그램이 동작하도록 했습니다.

---

## 사용 기술
- **Language**: C
- **Data Structure**: Singly Linked List
- **Algorithm**: Index Compression, Binary Radix Sort
- **System APIs**:
  - `write`
  - `malloc`
  - `free`
  - `exit`
